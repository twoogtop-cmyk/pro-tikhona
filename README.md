<h1 align="center">Тихон</h1>

<p align="center"><b>главный по тропам</b></p>

<p align="center">Приложение сервиса <b>Тихон VPN</b> для Android.<br>
Лисичка Тихон знает все тропы: найдёт короткий путь до YouTube, Telegram и любимых сайтов —<br>даже когда оператор включает «белые списки».</p>

---

## Что умеет

- **Одна кнопка.** Подключение в один тап — приложение само выбирает лучший путь.
- **Тропы в обход «белых списков».** Когда мобильный оператор оставляет только «разрешённые» сайты, Тихон находит обходную тропу — YouTube, Telegram и всё остальное продолжают работать.
- **Устойчивая связь.** Если одна дорога закрыта, Тихон сам переходит на другую и возвращается, когда она снова открыта.
- **Быстрые протоколы.** VLESS TCP и XHTTP.
- **Личный кабинет.** Вход через Telegram-бота или Яндекс ID, баланс, тарифы, оплата, трафик и устройства — прямо в приложении.
- **Выбор приложений.** Можно пускать через VPN только нужные приложения или, наоборот, исключать.

## Установка

1. Скачайте APK с сайта приложения: **[tihon.website](https://tihon.website)** → «Скачать для Android»
   (прямая ссылка: [ProTikhona-latest.apk](https://tihon.website/download/ProTikhona-latest.apk),
   для старых 32-битных телефонов — [ProTikhona-latest-armeabi-v7a.apk](https://tihon.website/download/ProTikhona-latest-armeabi-v7a.apk)).
   Если сайт не открывается — запасной вариант: раздел [Releases](../../releases/latest) здесь, на GitHub.
2. Разрешите установку из этого источника, когда Android спросит.
3. Откройте приложение и войдите через Telegram-бота Тихон VPN или Яндекс ID.

Требуется Android 8.0 и новее. Обновления приложение проверяет само: когда выходит новая версия, появится окно «Вышла новая версия» с кнопкой «Установить».
